# Таргет `reviewer-debug` — упавшие прогоны AI-ревью

Когда `reviewctl` в CI падает, ревью в `reviewer` не появляется, а в GitLab нет
артефактов джобы. Вместо них `reviewctl` присылает в reviewsrv бандл: метаданные прогона
и файлы из рабочей директории раннера. Упавший прогон присылает бандл всегда, удачный —
только если в CI включена отладочная выгрузка.

Только `GET`. Список и страница бандла — **HTML**: приходят текстом, `jq` к ним не
применить. Артефакты — JSON или текст.

## Разрешённые пути

| Путь | Зачем |
|---|---|
| `/v1/debug/storage/` | список прогонов, новые сверху: When, Project, MR, Branch, Runner, Model, Status, Cost, Files, Error |
| `/v1/debug/storage/<uid>/` | бандл: метаданные, текст ошибки, причина, `reviewId`, список файлов с размерами |
| `/v1/debug/storage/<uid>/review.json` | один артефакт по имени из списка файлов |

`<uid>` — UUID бандла, он в ссылках списка. Файлы, которые бывают:

- `claude-output.json`, `opencode-output.jsonl`, `direct-output.jsonl` — транскрипт
  раннера: весь разговор с моделью, вызовы инструментов, прочитанный код, в последней
  строке — итог и стоимость. Все три — NDJSON, событие на строку, `.json` в имени
  ничего не меняет;
- `review.json` — то, что раннер успел собрать для загрузки в `reviewer`;
- `R1.<ветка>.md` и следующие — разделы ревью в markdown.

## Статус и причина

`Status`: `ok`, `failed`, `timeout`, `cancelled` (джобу отменили — не сбой). У неуспешного
прогона `Reason`:

| Причина | Что случилось |
|---|---|
| `billing` | у провайдера модели кончились деньги |
| `auth` | ключ API неверный или не задан |
| `rate_limit` | лимит провайдера, повторы не помогли |
| `api_error` | 5xx, перегрузка или оборванный поток провайдера, повторы не помогли |
| `max_rounds` | раннер `direct` исчерпал раунды, не сдав ревью |
| `truncated` | раннер `direct`: раунды подряд обрезаны лимитом выходных токенов |
| `not_submitted` | раннер `direct`: модель остановилась, не сдав ревью |
| `timeout`, `cancelled`, `other` | по названию |

Если `reviewId` есть — ревью успели создать до сбоя, оно читается через `reviewer`.

## Грабли

- **Это кольцо в памяти.** Рестарт reviewsrv стирает все бандлы; старые вытесняются
  новыми. Файлы хранятся только у самых свежих бандлов, у остальных — метаданные и
  `evicted` вместо числа файлов.
- **Транскрипт не сузить `jq`.** NDJSON — не один JSON-документ, поэтому приходит
  текстом, и свой `jq` к нему не применяется. Обрезка по `max_bytes` оставляет начало,
  а итог прогона — в последней строке: он почти всегда теряется. Ошибку, причину и
  стоимость берите со страницы бандла; транскрипт — чтобы увидеть, что раннер делал
  до сбоя.
- **`review.json` — обычный JSON**, его `jq` сужает.
- **Секреты из транскрипта режутся** правилами профиля, но код и промпт — нет: это
  ровно то, что модель прочитала в репозитории.
