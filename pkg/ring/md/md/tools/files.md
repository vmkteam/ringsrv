# Файлы через `api_call`

У таргета с файлами есть путь `/files/download?file=<id>`: на него отвечает сам ringsrv, а не
апстрим. Он находит файл через API таргета, проверяет, что файл лежит в публичном канале,
скачивает его (не больше 10 МБ) и отдаёт содержимое. Где взять id файла — в шпаргалке таргета:
`help(["slack"])`.

`default_jq` профиля к этому пути не применяется: ответ формирует сам ringsrv. Свой `jq` вызова
работает, редакция PII таргета — тоже.

## Что приходит

- **Текст** (`csv`, `tsv`, логи, `txt`, `json`, `yaml`, `xml`, `html`, `sql`, `md`) — строками
  `"N: …"`, нумерация с 1, как у `code_read`: `total_lines`, `line_from`, `line_to`, `lines`.
  `encoding` есть, если файл был не в UTF-8 (`windows-1251` — выгрузка из 1С, `utf-16`).
- **Картинка** (`png`, `jpeg`, `gif`, `webp`) — отдельным блоком ответа: в `data` описание файла,
  в `image.content` номер блока, `image.width` и `image.height`. Большие уменьшены до 1568 px по
  длинной стороне. Не больше 4 картинок и 3 МБ картинок на вызов: остальные приходят с
  `Truncated` — запросите их отдельным вызовом.
- **Книга Excel** (`xlsx`, `xlsm`) — строками одного листа: строка файла N — это строка листа N,
  ячейки через табуляцию, пустые строки листа остаются пустыми строками. `sheet` — какой лист,
  `sheets` — все листы книги. Без `sheet` — первый нескрытый лист; `sheet` — имя листа или его
  номер с 1. Даты — в ISO (`2027-01-01`, `2027-01-01 12:00:00`), у формулы — её значение,
  перенос строки и табуляция внутри ячейки — пробел.
- **Архив** (`zip`) — без `entry` оглавление: строки `размер\tизменён\tимя`, `header` называет
  колонки, `grep` ищет по именам. `entry=<имя из оглавления>` — один файл архива по тем же
  правилам: текст, картинка или книга (тогда работает и `sheet`). Архив в архиве не
  открывается.

## Параметры

| Параметр | Что |
|---|---|
| `file` | id файла — обязателен |
| `offset` | сколько строк пропустить; нумерация после них продолжается |
| `limit` | сколько строк вернуть, по умолчанию 200, не больше 1000 |
| `grep` | только строки с подстрокой, без учёта регистра; `matched` — сколько их всего от `offset` |
| `sheet` | лист книги: имя или номер с 1 |
| `entry` | файл архива: имя из оглавления |

`next_offset` — продолжение: ответ упёрся в `limit` или, при `truncated: true`, в размер ответа.
У таблицы (`csv`, `tsv`, лист книги), прочитанной не с начала или через `grep`, `header` — её
первая строка: имена колонок не теряются.

## Грабли

- **Большой файл — только `grep` или окнами.** Таблица на сотни килобайт целиком в ответ не
  влезет: ищите строку `grep`, читайте `offset`/`limit` и продолжайте с `next_offset`.
- **`;` в `grep` кодируйте как `%3B`**: иначе он делит параметры, как `&`. В CSV из 1С
  разделитель — как раз `;`. Табуляция — `%09`.
- **Имя в `entry` — целиком, с папками**, как в оглавлении: `export/остатки.csv`, `/` можно
  не кодировать.
- **`sheet` и `entry` только там, где есть лист и архив**: `sheet` у `csv` или `entry` у
  не-архива — `BadArgs`, а не молчаливое «всё равно прочитал».

## Отказы

- `FileNotPublic` — файл не в публичном канале (приватный канал, личка).
- `FileTooLarge` — больше 10 МБ; файл архива, который распаковывается больше чем в 10 МБ;
  картинка, которую не развернуть в памяти (больше 24 Мп); книга, лист которой больше 32 МБ
  текста.
- `UnsupportedFileType` — `docx`, `pdf`, `xls` (старый Excel), `rar`, `7z` и прочее двоичное;
  зашифрованный файл архива; книга или архив, которые не читаются; картинка на таргете, где
  включено маскирование PII, — её не замаскировать.
